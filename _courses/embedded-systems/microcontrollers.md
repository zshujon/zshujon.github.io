## Microcontrollers and Architecture

Microcontrollers are the heart of embedded systems.

### Microcontroller vs Microprocessor

**Microcontroller**:
- Integrated system (CPU, memory, I/O)
- Lower power consumption
- Cost-effective

**Microprocessor**:
- Requires external components
- Higher performance
- More expensive

### Common Architectures

#### Harvard Architecture
- Separate program and data memory
- Faster execution
- Used in most microcontrollers

#### Von Neumann Architecture
- Shared memory for program and data
- Simpler design
- Used in microprocessors

### Popular Microcontroller Families

- **Arduino**: ATmega series
- **ARM Cortex-M**: STM32, NXP
- **PIC**: Microchip
- **ESP32**: Wi-Fi/Bluetooth enabled

### Peripherals

- Timers/Counters
- ADC/DAC
- UART, SPI, I2C
- PWM
- Interrupts
