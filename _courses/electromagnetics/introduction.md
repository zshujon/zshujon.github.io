## Vector Analysis and Coordinate Systems

Vector analysis is the mathematical foundation for understanding electromagnetic fields.

### Vector Operations

#### Basic Operations
- Addition and subtraction
- Scalar multiplication
- Dot product (scalar product)
- Cross product (vector product)

### Coordinate Systems

#### Cartesian Coordinates (x, y, z)
- Orthogonal system
- Constant unit vectors

#### Cylindrical Coordinates (ρ, φ, z)
- Useful for circular symmetry
- Variable unit vectors

#### Spherical Coordinates (r, θ, φ)
- Ideal for spherical symmetry
- Variable unit vectors

### Vector Calculus

- Gradient (∇f)
- Divergence (∇·A)
- Curl (∇×A)
