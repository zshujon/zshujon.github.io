## Vectors and Vector Operations

Vectors are fundamental mathematical objects in multivariable calculus.

### Vector Representation

A vector in 3D space:
**v** = v₁**i** + v₂**j** + v₃**k**

### Magnitude

|**v**| = √(v₁² + v₂² + v₃²)

### Vector Operations

#### Addition
**u** + **v** = (u₁+v₁)**i** + (u₂+v₂)**j** + (u₃+v₃)**k**

#### Scalar Multiplication
c**v** = cv₁**i** + cv₂**j** + cv₃**k**

#### Dot Product
**u**·**v** = u₁v₁ + u₂v₂ + u₃v₃

Properties:
- Commutative
- Distributive
- Result is a scalar

#### Cross Product
**u**×**v** = |**i** **j** **k**|
              |u₁  u₂  u₃|
              |v₁  v₂  v₃|

Properties:
- Anti-commutative
- Result is a vector
- Perpendicular to both vectors

### Applications

- Physics: Force, velocity, acceleration
- Engineering: Moments, torque
- Computer graphics: 3D transformations
