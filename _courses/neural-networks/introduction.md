## Introduction to Neural Networks

Neural networks are computational models inspired by biological neural systems.

### What is a Neural Network?

A neural network is a computing system made up of interconnected nodes (neurons) that process information using a connectionist approach.

### Biological Inspiration

- **Neurons**: Basic processing units
- **Synapses**: Connections with weights
- **Activation**: Threshold-based firing

### Artificial Neuron

Components:
1. **Inputs**: x₁, x₂, ..., xₙ
2. **Weights**: w₁, w₂, ..., wₙ
3. **Bias**: b
4. **Activation Function**: f(z)

Output: y = f(∑wᵢxᵢ + b)

### Common Activation Functions

- **Sigmoid**: σ(z) = 1/(1+e⁻ᶻ)
- **ReLU**: f(z) = max(0, z)
- **Tanh**: tanh(z)
- **Softmax**: For classification

### Network Architectures

- **Feedforward**: Information flows forward
- **Recurrent**: Feedback connections
- **Convolutional**: Spatial processing
- **Transformer**: Attention-based

### Applications

- Image recognition
- Natural language processing
- Speech recognition
- Game playing
- Autonomous vehicles
